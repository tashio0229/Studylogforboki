# 型カード② 全部 vs 直接・固定費調整

**核心（一言）**: ==利益の差＝固定製造原価が「在庫に乗る」か「期間費用になる」かの差。調整対象は在庫4つ全部==

> [!todo] 着手前チェック（毎回白紙に書く）
> 1. 直接原価計算P/Lの**型**を書く: 売上 → 変動売上原価 → 変動製造マージン → 変動販売費 → **限界利益** → 固定費 → 営業利益
> 2. 利益差額 ＝ **期末**在庫中の固定費 − **期首**在庫中の固定費（==期首を忘れるな==）
> 3. 固定費調整の対象は **期末仕掛品＋期末製品−期首仕掛品−期首製品** の4つ

## 型の整理

| 論点 | 型 |
|---|---|
| P/Lの並び | 変動費を先に全部引いて限界利益、その後に固定費一括 |
| 営業利益の差額 | 期末在庫固定費 − 期首在庫固定費（生産>販売なら全部原価の方が利益大） |
| 固定費調整・転がし法 | **要素別**に在庫へ追跡 |
| 固定費調整・一括法 | **金額比**で按分（**変動加工費を配賦基準**とするパターンに注意） |
| 直接標準原価計算 | 標準ベースで同じ調整。一括法の按分基準が詰まりどころ |
| セグメント別P/L | 貢献利益 ＝ 限界利益 − **個別**固定費（共通固定費は配賦しない） |

> [!warning] つまずき履歴（実績）
> - 例3: 「期首在庫の固定費」を見落として△ — 差額式の**期首**が抜けやすい
> - 例4: 転がし法を忘れた回あり — 転がし＝要素別／一括＝金額別の対で覚える
> - 例5: 「変動加工費を配賦基準とする一括法」でミス — 按分基準の読み取りが律速
> - 例6: ○化済み（個別固定費/共通固定費の切り分け定着）
