# 型カード① 差額原価の意思決定

**核心（一言）**: ==埋没原価を消してから、差額原価＋機会原価だけで比較する==

> [!todo] 着手前チェック（毎回白紙に書く）
> 1. この意思決定で**変わる原価**と**変わらない原価**を仕分ける（変わらない＝埋没→線で消す）
> 2. **機会原価**（他の選択肢を捨てることで失う利益）を忘れずに足す
> 3. 案ごとの差額損益を比較して結論

## 出題バリエーションと型

| 型 | 判断式 |
|---|---|
| 受注可否 | 差額収益 vs 差額原価。**固定費は原則無関係**（専用固定費・能力超過の残業だけ差額原価に含める） |
| 自製 or 購入 | 自製＝変動費＋**回避可能固定費** vs 購入原価。遊休設備の転用益＝機会原価 |
| 追加加工の可否 | 差額収益（加工後売価−加工前売価）vs 追加加工費。**結合原価は埋没** |
| セグメント廃止 | 個別固定費＝回避可能／共通固定費＝埋没。**廃止すると売上高も消える**のを忘れない |
| 価格低限 | 埋没原価を除いた**差額原価が下限ライン** |
| マークアップ | 全部原価/製造原価/変動費 — **掛け先（分母）が変わるだけ** |
| 制約条件1つ | **制約1単位あたり限界利益**が大きい製品を優先 |
| 制約条件2つ以上（LP） | 制約式を図示→**実行可能領域の頂点を総当たり** |
| 経済的発注量（EOQ） | $\sqrt{\dfrac{2 \times 年間需要量 \times 1回発注費}{1個あたり年間保管費}}$ ／ 発注点＝1日使用量×調達日数＋安全在庫 |

> [!warning] つまずき履歴（実績）
> - 例11: 方針は正しいのに**計算ミス**で△ — ロジックは定着済み、電卓・集計の精度が律速
> - 例5: 「新鮮な気持ちで解けば解ける」— **疲労時のケアレスミス蓄積**が敵
> - 例13: 「なぜ固定費を計算しない？」→ 変わらない原価は判断に無関係、が腹落ちして解決
