# プロジェクト: 業務棚卸シート（財務担当）たたき台

## 概要
- 経理財務課の業務棚卸シートを 6/30 までに提出する。
- 目的（依頼メールより）: 業務の可視化／属人化の解消／業務負荷の是正／BCP 強化。
- **自分の特性**: 財務担当ゆえ日次の定型業務が薄く、突発・随時業務が多い。記憶ベースで埋めようとすると漏れる → **証憑（痕跡）から逆引きする** のが正攻法。

## 進め方（2階建て＋時間配分）

### 方針の核
1. **決算業務** = 既存の決算スケジュール表／分担表があるので **コピペで写経**。記憶に頼らない。（自分が割り振り担当なので一番速い）
2. **突発・随時業務** = 記憶ではなく **証憑を時系列スキャンして拾う**（送信メール／共有フォルダ更新履歴／ネットバンキング／仕訳／稟議）。
3. **頻度の置き方**: 突発は「随時／不定期」とし、**年間で何回くらい・年間/月間の合計時間目安** で書く（1回あたりにこだわらない）。
4. **属人度を必ず立てる**: 「自分しかできない」業務に印を付ける。これが棚卸しの組織的価値（BCP・分担見直し）であり、同時に「休みやすさ・人員要求」の自分の武器にもなる。

## ③ 突発・随時業務の「トリガー」洗い出し（記憶のフック）
> 「何が起きると自分が動くか」で思い出すと突発業務が拾える。

- 大口の支払/入金が発生したとき
- 借入・返済・借換のタイミング
- 銀行から依頼・打診が来たとき
- 監査法人から依頼が来たとき
- 役員・他部署から資金/数字の照会が来たとき
- 制度改正・新会計基準が出たとき
- システム障害・バージョンアップ・証明書期限
- 新規取引先・新規契約・新規口座
- 災害・資金ショート懸念などBCP事象

### 決算業務の取り込み手順
1. 直近の決算スケジュール表／分担表を開く
2. 自分が割り当てている／実施しているタスクを行ごとにコピペ
3. 頻度＝四半期/中間/期末で分類、繁忙時期・期限を記入
4. 属人度・マニュアル有無を立てる（割り振り担当として一番分かっているはず）
