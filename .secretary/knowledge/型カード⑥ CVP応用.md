# 型カード⑥ CVP応用

**核心（一言）**: ==「目標利益」の欄に「資本×目標資本利益率」を代入するだけ。感度分析は変化項目を先に置換==

> [!todo] 着手前チェック（毎回白紙に書く）
> 1. 普通のCVP式を書く: 売上S − 変動費 − 固定費 ＝ 利益
> 2. 資本利益率系なら、利益の欄に **資本×目標資本利益率** を入れる
> 3. 変動的資本があるなら 資本＝変動的資本率×S＋固定的資本 として**Sの方程式**にする
> 4. 感度分析は「何がどれだけ変わるか」を**先に数値で置換**してから普通に解く

## 型の整理

| 論点 | 型 |
|---|---|
| 資本回収点売上高 | 目標利益 ＝ 資本×目標資本利益率 を代入して S を解く |
| 変動的資本と固定的資本 | 目標利益 ＝（変動的資本率×S＋固定的資本）×目標資本利益率 → Sの1次方程式 |
| 感度分析①② | 文章題の変化条件（単価↓10%等）を**先に数式へ置換**。複数条件は同時代入 |
| 全部原価計算のCVP | 全部と直接の利益差＝**操業度差異**。BEP＝営業利益0から**逆算** |
| 安全余裕率 | 安全余裕率＋損益分岐点比率＝100%（補数関係） |
| 経営レバレッジ | 係数＝限界利益÷営業利益。売上増加率×係数＝営業利益増加率 |
