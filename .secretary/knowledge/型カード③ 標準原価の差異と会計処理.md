# 型カード③ 標準原価の差異と会計処理

**核心（一言）**: ==仕掛品には標準配賦額、差異は別勘定。配合・歩留は「まずkg換算」が第一手順==

> [!todo] 着手前チェック（毎回白紙に書く）
> 1. 記帳方法はどれか: パーシャル／シングル／**修正パーシャル**（借方＝実際数量×標準価格）
> 2. 配合差異・歩留差異が出たら**個数→kgベース換算を最初にやる**
> 3. 正常仕損があるなら==原価標準そのものに仕損費が上乗せされる==（1個あたり標準が変わる！）

## 型の整理

| 論点 | 型 |
|---|---|
| 勘定記入 | パーシャル＝実際で入れて仕掛品内で差異／シングル＝標準で入れる／修正パーシャル＝借方は実際数量×標準価格・**価格差異は費目別／数量差異は仕掛品** |
| 原価差異の会計処理 | **少額→売上原価**へ／**多額→棚卸資産へ配分**（ころがし＝要素別／一括＝金額別） |
| 材料受入価格差異 | 材料の**払出先**（仕掛品/製品/売上原価/期末材料）へ配分する多段構造 |
| 正常仕損 | 発生点 vs 進捗度で「完成品のみ負担/両者負担」を判定＋**原価標準への上乗せ** |
| 減損 | 標準原価計算では**どこで減損しても製品原価は一定** |
| 配合・歩留差異 | kgに揃えて長方形分割。投入基準の標準減損量の逆算に注意 |
| 操業度差異 | ==求め方が2通りある==（未消化・講義#16で確認予定のまま） |

> [!warning] つまずき履歴（実績）
> - 例11: 仕損費の配分はできたのに「**原価標準も変わる**」を忘れて惜しい△（7/9に詰まり1点特定）
> - 例14: 個数→kg換算を忘れがち — kg換算を第一手順に固定する
> - 例13: ○化済み（減損の発生点非依存が定着）
> - 例15・16: 「もう一回講義を見ないといけないかも」— 独学限界のサイン、講義戻り推奨
